# Cronograma de Aulas

Este projeto é uma página simples em HTML para gerar um cronograma de aulas com:

- seleção de curso, carga horária e duração da aula
- definição da data da primeira aula
- escolha de dias de aula
- marcação de feriados
- cadastro de docentes por dia
- exportação para PDF

## Como usar

1. Abra o arquivo `index.html` em um navegador.
2. Preencha os dados do curso e da turma.
3. Clique em "Gerar cronograma".
4. Use "Salvar em PDF" para exportar a página.

## Arquivos

- `index.html` — interface principal do cronograma
- `logosenac.PNG` — imagem usada no cabeçalho
